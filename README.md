# Healthcare Analytics Dashboard

## Project Overview

This project is an interactive Healthcare Analytics Dashboard developed
using **Microsoft Excel**. It analyzes hospital patient, appointment,
revenue, and medical-cost data to help summarize key operational and
financial metrics.

The workbook contains **10,000 patient records** and is organized into a
source-data sheet, Pivot Table analysis sheets, and four dashboard
sheets.

## Tools and Excel Features

-   Microsoft Excel
-   Pivot Tables
-   Pivot Charts
-   Slicers and interactive filtering
-   Data summarization and visualization

## Dataset Description

The source dataset includes patient and hospital information such as: -
Patient ID, age, gender, and city - BMI and chronic disease -
Appointment type, department, symptoms, and severity - Doctor experience
and consultation fee - Insurance and appointment date/month -
Booking-to-appointment days and waiting time - Previous appointments and
missed appointments - Hospital rating and patient satisfaction score -
Medicine cost, test cost, total bill, and appointment status

## Dashboard Sections

### 1. Patient Overview Dashboard

Explores the patient population through: - Total number of patients -
Gender distribution - Patients by city - Patients by age group -
Patients by chronic disease

### 2. Appointment Analysis Dashboard

Examines appointment activity, including: - Scheduled appointments -
Walk-in appointments - Emergency appointments - Average waiting time -
Appointment trends by month

### 3. Revenue and Medical Cost Dashboard

Reviews hospital financial performance through: - Total revenue -
Average bill amount per patient - Revenue by department - Medicine
costs - Test costs

### 4. Cost and Department Analysis Dashboard

Provides additional cost comparisons, including: - Average medicine and
test costs - Test costs by department - Average bill amount by city -
Department-level financial comparisons

## How to Use

1.  Download the Excel workbook from this repository.
2.  Open it using Microsoft Excel.
3.  Navigate through the four dashboard sheets.
4.  Use the available slicers and filters to explore the data.
5.  Review the Pivot Table sheets for supporting summaries.

**Note:** For the best experience with Pivot Tables, charts, and
slicers, open the workbook in a desktop version of Microsoft Excel. Some
interactive features may not work fully in other spreadsheet
applications or mobile viewers.

## Project Objective

The objective of this project is to practice Excel-based data analysis
and transform raw healthcare data into meaningful summaries and visual
insights that can support better understanding of patient trends,
appointment operations, and hospital costs.
